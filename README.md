# Практическое задание к лекции №7

## Обеспечение сетевого трафика предприятия

**Выполнила:** Гороховская Дарья

**Группа:** Б1123-38.03.05ба(2)

**Предприятие:** «ТехноПрофи».

## Цель работы

Совершенствование системы мониторинга сетевого трафика и оценка экономической эффективности её внедрения.

## Задание 1. Анализ и улучшение

Реализованы следующие функции:

- Генерация 10 000 записей сетевого трафика за 24 часа.
- Обнаружение потенциальных DDoS-атак.
- Ведение журнала аудита событий безопасности.
- Формирование уведомлений Telegram в демонстрационном режиме.
- Визуализация результатов анализа.

При тестировании система обнаружила активность в размере 500 пакетов в секунду при установленном пороге 100 пакетов в секунду. Событие зарегистрировано в журнале аудита с уровнем опасности HIGH.

## Задание 2. Бизнес-кейс

| Показатель | Значение |
|---|---:|
| Годовая экономия | 3 000 000 руб. |
| Затраты первого года | 650 000 руб. |
| Чистый экономический эффект | 2 350 000 руб. |
| ROI | 361,54% |

Расчёт выполнен на основе условных экономических показателей учебного предприятия.

## Используемые технологии

Python, Google Colab, Pandas, NumPy, Matplotlib, JSONL, Telegram Bot API.

## Запуск проекта

Для запуска необходимо открыть блокнот IPYNB в Google Colab и последовательно выполнить все кодовые ячейки.

Код, таблицы, графики и результаты выполнения представлены в блокноте. Журнал аудита сохранён в отдельном файле audit_log.jsonl.

Реальная отправка уведомлений в Telegram не проверялась.

## Заключение

Разработан учебный прототип системы мониторинга сетевого трафика, позволяющий обнаруживать потенциальные угрозы, регистрировать события безопасности и формировать уведомления. Выполнена оценка экономической эффективности внедрения системы.
